# DPP — برنامج تسيير مؤسسة التكوين والتربصات

برنامج مكتبي لـ Windows بالعربية (RTL) لإدارة التكوينات والأقسام والأساتذة، مع **محرك جدولة حقيقي**
(Google OR-Tools CP-SAT) يبني جداول جميع الأقسام معاً ولكامل فترة التكوين.

## التشغيل السريع على Windows

| الهدف | الأمر |
|---|---|
| تشغيل من المصدر | انقر مرتين على `run_dev.bat` (ينشئ بيئة Python ويثبت المكتبات أول مرة) |
| بناء ملف EXE | انقر مرتين على `build_exe.bat` ← الناتج: `dist\DPP\DPP.exe` |
| فحص ذاتي للنسخة المبنية | `dist\DPP\DPP.exe --selftest` (يعمل في مجلد مؤقت، لا يلمس بياناتك) |

المتطلب الوحيد: **Python 3.11 أو 3.12 (64-bit)** مع خيار «Add to PATH» أثناء التثبيت.
يمكن نسخ مجلد `dist\DPP` كاملاً إلى أي حاسوب Windows وتشغيل `DPP.exe` دون تثبيت Python.

أول تشغيل: تُطلب كلمة مرور لإنشاء **حساب المدير الوحيد** (6 أحرف على الأقل).

## أين تُحفظ البيانات؟

- قاعدة البيانات: `%APPDATA%\DPP\dpp.sqlite` (خارج مجلد البرنامج؛ لا تحتاج صلاحيات مدير)
- النسخ الاحتياطية: `%APPDATA%\DPP\backups\` (قابل للتغيير من الإعدادات ← النسخ الاحتياطي)
- سجل الأخطاء التقنية: `%APPDATA%\DPP\dpp.log`

## النسخ الاحتياطي والاستعادة

- **نسخة الآن**: شريط الأوامر ← الرئيسية ← «نسخة احتياطية الآن» (أو `Ctrl+Shift+S`).
- **تلقائي**: نسخة يومية عند التشغيل والإغلاق، مع الاحتفاظ بآخر N نسخة (الافتراضي 10).
- **الاستعادة**: الإعدادات ← النسخ الاحتياطي ← اختر نسخة ← «استعادة». قبل الاستبدال يفحص البرنامج سلامة
  النسخة (`PRAGMA integrity_check`)، ويعرض تاريخها ومحتواها، ويأخذ نسخة من بياناتك الحالية، ثم يفحص القاعدة بعد
  الاستعادة. النسخة التالفة تُرفض ولا يتغير شيء.

## الجديد في الإصدار 1.6

- **الجدول العام:**
  - بطاقات الشريط بلا وقت، والمدة تُختار عند وضعها (من 30 دقيقة إلى 4 ساعات، أو اليوم كاملاً).
  - البطاقة الأقصر من خانتها تُرسم بحجمها الحقيقي في موضع الإفلات.
  - اللقب على البطاقة، مع أول حرف من الاسم إذا تشابه لقبان.
  - أزرار التراجع والإعادة تكتب اسم العملية، ومعها قائمة آخر 20 عملية.
  - تحت كل بطاقة في الشريط «باقي X سا · Y%» للقسم المحدد، وقائمة لترتيب البطاقات.
- **ألوان البطاقات:** لوحات جاهزة، الشدة، لون لكل عائلة، لون الكتابة، ومعاينة حية (الإعدادات ← الجدول العام).
- **القائمة الجانبية:** لا يبقى فراغ عند طيّها، والأسماء ملتصقة باليمين، وتظهر كتلميح في الوضع المطوي.
- **إصلاح PDF:** النص المضبوط وبالتطويل يخرج في PDF والطابعة كما في المعاينة.
  - أُضيف اختبار آلي يقارن المعاينة بالـ PDF، وزر «معاينة PDF» في المحرر.
- **قوالب Word:** قالب لكل طور (وقالب خاص لقسم عند الحاجة) يُعدَّل في Word ويُستورد تلقائياً بعد الحفظ والفحص.
  - PDF يُنشأ عبر Word المثبّت، وإلا بمحرك البرنامج.
- **تصدير الأسبوع كاملاً:** مجلد باسم الأسبوع، فيه Word وPDF لكل قسم وملف يجمع كل الأقسام.
- **صفحة «الأسابيع»:**
  - المعلومات والحالة والتعارضات ونسب التنفيذ وآخر تعديل، وملاحظة لكل أسبوع.
  - الأوامر: فتح الأسبوع، تصديره، نسخه، اعتماده.

- **الخفارة والخدمات:** نظام منفصل بتناوب عادل ويدوي، طباعة وExcel وإحصائيات، وإدراج في الجدول عند الطلب.
- **المخطط الأسبوعي:** ما ينقص هذا الأسبوع، ملخص الأيام، برمجة قسم واحد، أسبوع نموذجي، نسخ يوم، تبديل حصتين، قفل الحصص، وفحص الأسبوع.

## نسخة ويندوز 7 (DPP خفيف)

ويندوز 7 **لا يمكنه تشغيل النسخة الكاملة**: الواجهة مبنية على Qt 6 الذي أسقط دعم ويندوز 7،
وبايثون 3.8 هو آخر سلسلة تعمل عليه. لذلك توجد نسخة ثانية مستقلة:

| | النسخة الكاملة | **DPP خفيف** |
|---|---|---|
| النظام | ويندوز 10/11 | **ويندوز 7 فما فوق، 32 و64 بت** |
| التقنية | Python 3.12 + Qt 6 | Python 3.8 + **Qt 5 (PySide2)** |
| قاعدة البيانات | نفسها | **نفسها بالضبط** (`dpp.sqlite`) |
| إعداد الجدول الأسبوعي يدوياً | ✔ | **✔** |
| متابعة الأسابيع السابقة | ✔ | **✔** |
| طباعة وPDF للجدول | ✔ (محرر أوراق كامل) | ✔ (الجدول كما يظهر) |
| البرمجة الآلية (OR-Tools) | ✔ | ✘ — لا عجلات 32 بت |
| قوالب Word، محرر الأوراق، التقارير، الخفارة، الغياب | ✔ | ✘ |

**الاستعمال**: `DPP-Lite.exe` — يفتح قاعدة البيانات نفسها (أو «فتح قاعدة…» لاختيار ملف منقول بـ USB).
اختر التكوين والقسم والأسبوع، ثم اختر مادة من الشريط السفلي واسحب في اليوم لتحديد الوقت.
الزر الأيمن على حصة: الأستاذ، المدة، الحذف. Ctrl+Z / Ctrl+Y للتراجع والإعادة، Ctrl+P للطباعة.
التعارضات تظهر بإطار أحمر وتُطلب الموافقة قبل الوضع.

**البناء**: `pyinstaller --noconfirm dpp_lite.spec` ببايثون 3.8 (x86)، أو من GitHub Actions
(وظيفة `lite`) حيث تُرفع باسم `DPP-Lite-win7-x86`. التشغيل من المصدر: `python run_dpp_lite.py`.

## الجديد في الإصدار 1.7

- **واجهة «DPP الحديثة» هي الافتراضية**: قائمة جانبية داكنة مجمّعة (الجدولة / البيانات / المتابعة / النظام)
  بأيقونات ومؤشر نشط وقابلة للطيّ (Ctrl+B)، وشريط علوي فيه **مسار التنقل** (DPP ‹ المجموعة ‹ الصفحة)
  وعنوان الصفحة والبحث السريع و**مركز الإشعارات** (التعارضات، تذكيرات الرزنامة، التنبيهات المفتوحة)
  و**بطاقة المستخدم** بقائمتها، مع بطاقات بزوايا ناعمة وحقول وأزرار أوسع.
- لها **وضع فاتح ووضع داكن**؛ يُبدَّل بـ Ctrl+Shift+D أو من الإعدادات ← المظهر ← وضع الألوان.
- **الواجهات السابقة تبقى متاحة** كما هي من الإعدادات ← المظهر أو Ctrl+Shift+L:
  أ) غرفة العمليات، ب) السجل، ج) يوم بيوم.
- **التصدير إلى aSc Timetables**: صفحة «الاستيراد والتصدير» ← تبويب «التصدير إلى aSc» يصدّر أسبوعاً كاملاً
  (الأيام، الفترات، المواد، الأساتذة، القاعات، الأقسام، الأفواج، الدروس والبطاقات بمواضعها) إلى صيغة الاستيراد
  الرسمية في aSc ‏(XML). في aSc: ملف ← استيراد ← XML ثم احفظ باسم ‎.roz‎ — فتكتمل الدورة ‎.roz‎ ← DPP ← ‎.roz‎.
  (الكتابة المباشرة في ‎.roz‎ غير مدعومة: صيغة ثنائية مغلقة، وقارئ البرنامج لها مستخرج بالهندسة العكسية؛
  aSc نفسه يحوّل XML إليها.)
- **النصوص الطويلة تلتفّ** في كل الصفحات فلا تُقتطع أطراف الصفحة على الشاشات الضيقة.
- **الإعدادات بأقسام**: قائمة جانبية (المؤسسة والوقت، المظهر، الجدول العام، البرمجة والتعارضات، الطباعة،
  الأصوات، الحساب والأمان، النسخ الاحتياطي والبيانات، سجل العمليات) بدل شريط تبويبات طويل، و**منطقة خطر
  مفصولة** بإطار أحمر حول أزرار الاستعادة (تستبدل كل البيانات الحالية).
- **لون أساسي قابل للاختيار**: الإعدادات ← المظهر ← اللون الأساسي (أخضر عسكري، أزرق، نيلي، كستنائي، رمادي داكن)،
  لكل لون نسخته في الوضع الفاتح والداكن.
- **حالات فارغة احترافية**: أيقونة وعنوان وشرح وزر إجراء بدل سطر «لا توجد بيانات» في البطاقات الفارغة.

## الجديد في الإصدار 1.4

- **ثلاث واجهات** تُختار من الإعدادات ← المظهر: أ) غرفة العمليات (داكن، قائمة أيقونات)، ب) السجل (فاتح بشكل الورقة،
  والشريط لوحة جانبية)، ج) يوم بيوم (فاتح، تنقل علوي وتبويبات الأيام). (أُضيفت إليها «DPP الحديثة» في 1.7.)
- **الجدول العام**: اسم المادة كاملاً على البطاقة والشريط؛ لون لكل نوع مادة (عسكرية أخضر، اختصاص أزرق، عامة عسلي)
  بدرجة خاصة لكل مادة؛ البطاقة تملأ خانة الحصة. النقر على بطاقة في الشريط يعرض **أقرب الأوقات المتاحة**، والزر الأيمن
  على حصة ← «نقل سريع إلى وقت متاح». **بطاقة جديدة** (مادة موجودة أو جديدة) مع التثبيت في أول الشريط.
- **اختيار الأستاذ**: إضافة أستاذ جديد بكتابة اسمه (يُعيَّن للمادة واختصاص القسم)، والمشغول يظهر مع سبب التعارض.
- **الاستخلاف**: البحث في كل الأساتذة.
- **المقرر والتقدم** (صفحة واحدة): المقرر والمنجز (دوائر ونسب وساعات باقية)، التقدم ونسبة التنفيذ، الحجم الساعي
  الأسبوعي، المقرر، **التحليلات** (خريطة أقسام × مواد، مقارنة أقسام الاختصاص، تاريخ الانتهاء المتوقع، منحنى الساعات)،
  و**التنبيهات** الدائمة لمشاكل ملف المقرر والبيانات. ملف المقرر مرفق ويُدرج تلقائياً مرة واحدة.
- **مخطط التكوين**: شجرة التكوين ← الشهادة ← السنة ← الاختصاص ← الأقسام، مع النقل بالسحب، ومراحل الاحتياط بالأسابيع.
- **الأحداث**: المعنيون بالحضور أقساماً من شجرة.
- **تصميم ورقة الطباعة**: نصوص حرة (محاذاة، خط، لون، إطار، دوران، حقول تلقائية)، شبكة والتصاق، الورق والهوامش،
  تعديل الجدول (العروض بالسحب، الحدود والألوان، الأعمدة والأيام، الدمج)، وقوالب لكل نوع ← طور ← قسم، مع تراجع وإعادة.
- **الإعدادات ← الحساب**: مسح جميع البيانات والعودة إلى الصفر (بكلمة المرور).

## الجديد في الإصدار 1.3

- **الطباعة بالقالب الرسمي** (`Ctrl+P` أو زر «طباعة» في الجدول العام): نفس نموذج المدرسة — الأيام أسطر والحصص أعمدة،
  الرأس والمقرر والأسبوع بالحروف والفترة والتوقيعات. أبيض وأسود (الألوان اختيارية). قسم، كل الأقسام (ملف PDF لكل قسم)،
  أقسام طور، أستاذ، كل الأساتذة، قاعة، لأسبوع أو عدة أسابيع.
- **المعاينة قبل الطباعة** مع **التعديل مباشرة على الورقة**: أي نص (الرأس، المقرر، خانة، توقيع) يُعدّل بالنقر عليه؛
  عند الحفظ يسألك: في قالب هذا الطور، في قالب كل الأطوار، أو لهذه الطباعة فقط. طباعة، PDF، Excel.
- **ملف الأستاذ** (نقر مزدوج على الأستاذ، أو على اسمه في الجدول العام): ساعات كل أسبوع، الأقسام والمواد، برنامجه
  الأسبوعي على الورقة الرسمية، إجازاته وتعويضاته.
- **التعويض**: عند تسجيل إجازة يقترح البرنامج لكل حصة من يعوّضه (من درّس المادة لنفس القسم، ثم من يدرّسها، ثم نفس
  الاختصاص، ثم أي أستاذ متفرغ — والأقل ساعات أولاً). الحصة بلا معوّض تبقى في مكانها «بدون أستاذ» بالأحمر.
- **الحجم الساعي الأسبوعي** (تقدم المواد ← التبويب الثاني): ساعات كل مادة لكل قسم في كل أسبوع؛ نقر مزدوج يفتح الأسبوع
  في الجدول العام، و«تصحيح الرقم» يصحح خطأ استيراد دون لمس الحصص، ويُحتسب في نسبة التنفيذ.
- **صفحة المقرر**: استيراد تقرير «نسبة تنفيذ برامج التكوين» (Excel) — عمود المقرر فقط — مع مراجعة الطور والاختصاص لكل
  كتلة، والمواد غير المعروفة أو المتعارضة في «مواد تحتاج مراجعة» تعدّلها وتدخلها بنفسك.
- **الاختصارات العربية** مفصولة بفراغات («ف ت م» بدل «فتم»)، وأزرار **−** و**+** لحجم الجدول والشريط بدل «ص م ك».
- **الإعدادات**: بداية السنة الدراسية، نصوص القالب الرسمي وخطه، خيارات الطباعة، مهلة البرمجة وأوزانها، المدة الافتراضية،
  المواد المشتركة، عدد المعوّضين المقترحين، وما يظهر في الجدول العام.

## الجديد في الإصدار 1.1 (المرحلة أ)

- **الجدول العام** (الصفحة الرئيسية، `Ctrl+1`): كل الأقسام في شاشة واحدة، الأيام × الحصص، مثل aSc.
  انقر بطاقة لرفعها ← تتلوّن خانات صفها بالأخضر/الأحمر ← انقر خانة لوضعها (أو اسحبها). `Esc` إلغاء،
  `Delete` إعادة إلى الشريط السفلي، `Ctrl+Z / Ctrl+Y` تراجع/إعادة. عرض حسب الأقسام / الأساتذة / القاعات،
  تلوين حسب نوع المادة / الطور / القسم، «خيارات العرض» لإظهار أو إخفاء أي عنصر.
- **الهيكل**: تكوين ← طور (BMP2، BMP1، ESOC2، ESOC1، OF-R، ESO-R، I-ESO-R، I-HDT-R) ← اختصاص ← دورة ← قسم.
- **الفترات حسب الطور** مع تجاوز للقسم: العادي (8–10، 10–12، 12–13، 13–14، 14–16)، القاعدي المشترك
  (13:00–14:30، 14:30–16:00)، والليلية 17:00–00:00 لسنة أولى. فترة الغداء لكل طور/قسم.
- **استيراد الأسابيع السابقة من aSc** (الاستيراد ← الأسابيع السابقة): الحصص بتواريخها الفعلية، قابلة للتعديل،
  مع «الرجوع إلى الأصل المستورد»، وتجاهل التعارضات الموجودة أصلاً في الملفات.
- **المخطط الزمني (Excel)**: مراحل كل طور أسبوعاً بأسبوع حسب ألوان الخلايا.
- **قواعد المشاركة**: الرمي، التربية البدنية العسكرية، العدو الريفي، النظام المنظم، المحاضرات = حصص مشتركة؛
  غيرها: نفس الأستاذ في نفس الوقت = تعارض يُعرض عليك مع «تجاهل» أو «إصلاح».
- **ثلاثة أنماط للواجهة** (الإعدادات ← المظهر، أو `Ctrl+Shift+L`): عصري (افتراضي)، كلاسيكي (Ribbon)، تركيز
  (شريط رفيع + لوحة أوامر `Ctrl+K`).

## مسار العمل المقترح

1. **التكوينات** ← أنشئ تكويناً (التواريخ وأيام الراحة الأسبوعية).
2. **الاستيراد** ← ملف `6.roz` (المواد، الأساتذة مع فصل الرتبة، القاعات، الأقسام، الأفواج، الأهلية) أو Excel.
3. **المواد** ← فعّل «قابلة للمشاركة» للمواد التي تُدرَّس لعدة أفواج في حصة واحدة.
4. **المتطلبات** ← راجع الحجم الساعي الكلي والأسبوعي ومدة الحصة لكل فوج (المستوردة من .roz تقديرية).
5. **الرزنامة** ← العطل والامتحانات (تحجب الجدولة تلقائياً).
6. `Ctrl+G` ← «فترة التكوين كاملة» أو «أسبوع — جميع الأقسام» ← راجع الحصص المتعذرة وأسبابها ← احفظ.
7. **المخطط الأسبوعي** ← عدّل بالسحب والإفلات أو بالزر الأيمن ← «اعتماد».
8. سجّل الحصص المنجزة/المؤجلة، والغيابات والمستخلفين؛ تابع التقدم والتقارير.

## اختصارات لوحة المفاتيح

`Ctrl+1` الجدول العام · `Ctrl+3` لوحة التحكم · `Ctrl+2` المخطط · `Ctrl+K` لوحة الأوامر · `Ctrl+G` إنشاء جدول · `Ctrl+F` بحث سريع · `Ctrl+P` طباعة البرنامج الرسمي (معاينة) ·
`Ctrl+PgUp/PgDown` الأسبوع السابق/التالي · `Ctrl +/-` تكبير/تصغير الجدول · `Ctrl+B` اللوحة الجانبية · `F5` تحديث.

## البنية

```
dpp/
  app.py               نقطة التشغيل وتسجيل الدخول
  selftest.py          الفحص الذاتي للنسخة المبنية
  db/                  مخطط SQLite وطبقة الاتصال والحساب
  scheduler/engine.py  محرك الجدولة (CP-SAT): قيود صلبة + تفضيلات موزونة + تقرير التعذر
  services/            الجداول، الساعات، الغياب، الرزنامة، القوالب، النسخ الاحتياطي
  importers/           قارئ .roz (هندسة عكسية موثقة) + الاستيراد إلى القاعدة + Excel
  exporters/           نموذج التقارير + التصدير الحقيقي DOCX/XLSX/PDF
  ui/                  النافذة، Ribbon، الصفحات، المخطط التفاعلي، المظاهر
tests/                 45 اختباراً (pytest) على قواعد بيانات مؤقتة
```

## تشغيل الاختبارات

```
.venv\Scripts\activate
python -m pytest -q tests
```
لاختبار استيراد ملفك: ضع `6.roz` في `tests\data\` (غير مرفق في الحزمة لأنه يحتوي بيانات المؤسسة).
