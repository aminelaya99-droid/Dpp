## المرحلة 1 — الأساس
- هيكل المشروع `dpp/` (models, db, services, importers, printing, ui, tests).
- قاعدة SQLite عبر SQLAlchemy بكل الجداول (التكوينات، الأطوار، الاختصاصات، الفروع، المراحل، المواد، الأساتذة وربطهم، الأسابيع، الحصص، النسخة المستوردة، الأحداث، المقرر، التنبيهات، الإعدادات، قوالب الطباعة، الأسلحة والرمي).
- تسجيل دخول لحساب مسؤول واحد، أول تشغيل ينشئ الحساب.
- نافذة رئيسية RTL بقائمة جانبية، الصفحة الرئيسية، شاشة التكوينات (شجرة قابلة للتعديل، أعداد، نقل الفروع، تحرير المخطط الزمني).
- اختبارات: البيانات الأولية، الحساب، الشجرة، المراحل.

## المرحلة 2 — استيراد .roz
- محلل `dpp/importers/roz.py` (XML/zip/gzip، UTF-8/16)، دمج الفترات المتتالية، الحصص المشتركة، الأفواج.
- خدمة `dpp/services/roz_import.py`: إنشاء/مطابقة الفروع والمواد والأساتذة، حفظ النسخة الأصلية، الرجوع إليها، الاستبدال عند إعادة الاستيراد.
- شاشة «استيراد aSc»: اختيار عدة ملفات مع رقم الأسبوع، سجل النتائج، قائمة الأسابيع المستوردة وزر الرجوع.
- اختبارات على ملف نموذجي مصطنع (5 اختبارات).

## المرحلة 3 — المخطط الأسبوعي
- محرك التعارضات `services/conflicts.py` (منطق خالص) + `services/planner.py` (وضع/نقل/مدة/أستاذ مشغول/اقتراحات أوقات/نسخ أسبوع/لقطة للتراجع).
- شبكة مرسومة `ui/planner/grid.py`: العرض الرئيسي لكل الفروع، وعرض الفرع بتخطيطين، RTL، سحب وإفلات، الغداء والأحداث، إبراز التعارضات.
- الشريط السفلي لبطاقات المواد (بلا وقت، بحث، تصفية بالنوع، بطاقة جديدة مع التثبيت، الساعات المتبقية عند عرض فرع).
- نوافذ: تعيين الأستاذ/البديل، التعارض (تجاهل/تصحيح)، تعديل الحصة.
- لوحة التعارضات الجانبية مع التجاهل.
- شاشة الأساتذة والمواد.
- اختبارات: 11 للتعارضات، 4 لخدمة المخطط، 2 لواجهة المخطط دون شاشة.
