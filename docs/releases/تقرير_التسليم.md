## 2. الميزات المنفذة فعلياً

**محرك الجدولة (الأولوية 1 و2)**
- نموذج CP-SAT زمني (خانات 30 دقيقة) لأسبوع، لأقسام مختارة، أو **لجميع الأقسام معاً** بموارد مشتركة.
- قيود إلزامية: لا تزامن للأستاذ/القاعة/الفوج، الفوج الكامل يتعارض مع مجموعاته، الأهلية، عدم التوفر، الغياب،
  العطل والامتحانات وأيام راحة كل تكوين، استراحة الغداء، المدد المسموحة (1، 1.5، 2، 3، 4 سا، يوم كامل).
- **الحصة المشتركة لمواد محددة فقط** (خيار «قابلة للمشاركة» + رمز مشاركة + نفس الأستاذ).
- تفضيلات موزونة قابلة للضبط: توزيع المادة على الأيام، تقليل الفراغات، تفضيلات الأساتذة.
- عند التعذر: أفضل حل جزئي + سبب لكل حصة متعذرة + مشاكل البيانات (لا أستاذ مؤهل، مورد غير متاح…).
- **مخطط كامل لفترة التكوين**: توزيع الحجم الساعي على الأسابيع بالتناسب مع أيام الدراسة، جدول لكل أسبوع،
  ترحيل غير المبرمج للأسبوع التالي.
- **إعادة البرمجة بعد تعديل الرزنامة**: الحصص المولدة آلياً تُعاد برمجتها؛ المعتمدة واليدوية لا تُلمس وتُعرض للقرار.
- مسودة ← اعتماد ← إعادة فتح (رقم نسخة)، لقطات للرجوع إلى نسخة سابقة، لا تعديل تلقائي لجدول معتمد.
- اختبار الحجم الحقيقي: بيانات 6.roz كاملة (40 قسماً، 172 أستاذاً، 1120 متطلباً) ← 877 حصة في 63 ثانية مع
  تقرير صريح لما تعذر.

**الواجهة (الأولوية 3)**: Ribbon بثمانية تبويبات، لوحة جانبية، بحث سريع موحد، شريط حالة، قوائم سياقية، اختصارات،
مظهر فاتح/داكن/تلقائي محفوظ، حقول التاريخ والوقت تبقى LTR داخل واجهة RTL، تسجيل دخول بحساب مدير واحد.
- **المخطط التفاعلي**: منزلقات العرض/الارتفاع/التكبير، فلاتر (قسم/فوج/أستاذ/قاعة)، تنقل بين الأسابيع، سحب الحصص
  لنقلها مع فحص التعارض، **شريط بطاقات المواد** للفوج المحدد مع الساعات المتبقية والسحب لإنشاء حصة، قائمة سياقية
  (تعديل، نسخ، منجزة، تأجيل، إلغاء، تعويضية، استخلاف، سجل التغييرات، حذف)، نسخ/مقارنة أسبوعين.
- **لوحة التحكم**: 8 بطاقات من بيانات حقيقية قابلة للنقر والتخصيص والترتيب، مركز تنبيهات مع إجراء لكل تنبيه،
  مواعيد مع عد تنازلي، مخططات حلقية لتقدم الأقسام، مقارنة المبرمج/المنجز للأساتذة، عمليات سريعة.

**الساعات والغياب والاستخلاف (الأولوية 4)**: «مبرمج» ≠ «منجز»؛ الاستخلاف يُحتسب للمستخلف وحده مع حفظ الأصلي؛
المؤجل/الملغى لا يُحتسب؛ التعويضية مرة واحدة ولا تعويض مزدوج؛ الحصة المشتركة مرة للأستاذ ولكل فوج في تقدمه؛
اقتراح مستخلفين مؤهلين ومتفرغين (الأقل عبئاً أولاً) واقتراح تلقائي لكل حصص الغياب؛ تنبيه المواد المتأخرة مقارنة
بالمدة المنقضية بعد طرح العطل.

**الرزنامة (الأولوية 5)**: 12 نوع حدث، تلوين الأيام، حجب الجدولة، تنبيهات قبل 30/14/7/3/1 يوم أو مخصص، عرض في
لوحة التحكم، إشعار من شريط النظام عند توفره.

**القوالب والتصدير (الأولوية 6)**: مصمم قوالب (الورق، الاتجاه، الهوامش، الخطوط، الألوان، الحقول الظاهرة، الرأس،
التذييل، التوقيعات، الأبعاد) مع حفظ عدة قوالب؛ 10 تقارير؛ تصدير حقيقي DOCX (RTL، رأس/تذييل، رقم الصفحة، تكرار
العناوين) وXLSX (RTL، دمج، ألوان، ضبط الطباعة) وPDF (خط عربي مضمّن وتشكيل صحيح)؛ معاينة عبر عارض PDF.

**حماية البيانات (الأولوية 7)**: نسخ يدوي وتلقائي، مجلد مستقل، عدد نسخ محدد، فحص سلامة قبل وبعد الاستعادة،
نسخة أمان تلقائية قبل الاستعادة، سجل عمليات قابل للبحث، أرشفة التكوينات.

**الاستيراد**: قارئ `.roz` مبني على فحص فعلي للملف (التوقيع ASCTT، الإصدار 702، غير مضغوط، Windows-1256، بنية
السجلات موثقة في `dpp/importers/roz.py`)، مع معاينة ومكررات وتحذيرات ومعاملة واحدة؛ يستعمل اختصارات الأقسام التي
كتبتها في aSc (مثل bmp2-تسخين). استيراد Excel مع مطابقة الأعمدة والتحقق.

## 3. نتائج الاختبارات

- **33/33 اختباراً ناجحاً** (`pytest`) — قائمة كاملة في `tests_result.txt`.
- **الفحص الذاتي للنسخة المجمّدة (PyInstaller)**: 6/6 ناجحة (قاعدة البيانات، جدولة فترة كاملة، 18 صفحة بالمظهرين،
  التصدير الثلاثي، النسخ والاستعادة، إعادة الفتح). كشف هذا الفحص خللاً حقيقياً في التجميع (قوالب python-docx) وتم إصلاحه.
- **ملف DPP.exe لـ Windows (x86-64)**: بُني بـ Python 3.12 لـ Windows وPyInstaller داخل Wine 9.
  نجح الفحص الذاتي `DPP.exe --selftest` (6/6)، ونجحت الاختبارات الـ 33 على Python لـ Windows، وفُتحت نافذة الدخول
  والنافذة الرئيسية وأُغلقتا بنجاح (رمز الخروج 0) على شاشة افتراضية. لم يُجرَّب على جهاز Windows حقيقي بعد.
- فحص بصري لملفات DOCX/XLSX/PDF بعد فتحها في LibreOffice.

## 4. ما لم يكتمل وأسبابه

| الميزة | الحالة والسبب |
|---|---|
| أماكن الحصص ومدتها في `.roz` | لم يثبت تفسيرهما بيقين (فرضية المدة اتفقت مع البيانات في 94% فقط)؛ لذلك لا تُستورد، ويُنبَّه المستخدم. الحجم الأسبوعي المستورد تقديري. |
| الدروس بلا أستاذ في `.roz` | (عطل نهاية الأسبوع، امتحانات، تربصات) لا تتحول إلى متطلبات؛ تُذكر في التقرير لإضافتها كأحداث رزنامة. |
| مصمم القوالب | نموذج إعدادات مع معاينة PDF، وليس مصمماً مرئياً بالسحب. |
| الطباعة المباشرة | عبر فتح PDF في عارض النظام (لم يُضَف QPrinter مباشر). |
| إشعارات Windows | عبر QSystemTrayIcon؛ لم تُختبر على Windows. |
| Google Drive | غير منفذ (اختياري حسب البرومبت). |
| تعدد المستخدمين | حساب مدير واحد حسب قرارك. |
